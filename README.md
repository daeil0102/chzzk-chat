# chzzk chat

해당 프로젝트는 치지직 채팅을 자유롭게 설정해서 방송에 보여주는 프로젝트 입니다


## Java 버전

21


## 라이센스

Copyright (c) 2026 Teujaem

1. 상업적 이용이 가능합니다.
2. 2차 수정이 불가능 합니다. (fork 포함)
   - 예외사항
     - 리소스는 수정 가능합니다 (ex. config, images/**)
3. 2차 배포가 불가능 합니다.


## 사용법

### 실행 방법

- 윈도우 start.bat 실행
- 리눅스 start.sh 실행
- 맥OS start.command 실행

맥 이용 시 권한 설정이 필요합니다

### 접속방법

- http://localhost:8080 (config에서 수정용)
- http://localhost:8080/bidirectional (가운데)
- http://localhost:8080/unidirectional (왼쪽)
